3. Security reminders:
   - Pods run non-root (UID 10001) with readOnlyRootFilesystem=true and ALL Linux capabilities dropped.
   - Inject provider API keys via an external Kubernetes Secret (`--set secrets.existingSecret=<name>`).
   - Set `config.otelCaptureMessageContent="false"` (default) to avoid exporting raw prompts/PII to traces.
