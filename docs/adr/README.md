# Architecture Decision Records

This directory contains Architecture Decision Records (ADRs) documenting
significant architecture decisions made in the AI-Native Product Value System.

## Format

Each ADR follows a consistent structure:
- **Context**: Problem statement, constraints, and requirements
- **Decision**: Chosen architectural direction
- **Alternatives Considered**: Pros, cons, and rejection/selection verdicts
- **Consequences**: Positive, negative, and neutral trade-offs
- **Metadata**: Machine-readable YAML block for CLI indexing and traceability

## Status Lifecycle

- **Proposed**: Draft awaiting human/team review (including agent-generated drafts)
- **Accepted**: Approved and active architectural standard
- **Deprecated**: No longer recommended for new work
- **Superseded**: Replaced by a newer ADR
